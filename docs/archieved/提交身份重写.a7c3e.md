# 提交身份重写

## 现状

公开仓库的 Git 提交与 annotated tag 元数据使用了个人真实身份。当前源码文件未发现对应文本，但公开 commit、tag、分支、Pull Request、Release 和 Actions 记录仍可能暴露旧身份。仓库级 Git 配置已切换到 GitHub noreply 身份，本地受管历史已经完成匿名化重写，远端尚待替换。

## 目标

在不改变源码语义的前提下，清理仓库可控 Git 历史中的个人身份元数据，移除旧公开引用，使用新的匿名化提交身份重新建立发布链，并在本机安装 macOS arm64 版本。发布产物、证明和历史引用必须绑定到清理后的新提交；Windows 继续保持未支持状态。

## 影响范围

- Git 仓库：提交作者/提交者、annotated tag、分支和 Pull Request 引用。
- 发布系统：旧 Release、资产、签名证明、Actions 运行记录和新版本发布链。
- 本机：仓库级 Git 身份、macOS arm64 可执行文件及安装路径。
- 不涉及：产品运行时语义、Git 对象格式、源码功能和 Windows 支持范围。

## 架构示意

```text
旧公开 refs → 身份重写 → 旧远端引用清理 → 新版本 CI/Release → 本机安装
```
